## 🔬 Overview

This repository is designed as a progressive codebase covering the full lifecycle of modern software development and AI engineering:

1. **Foundational Mastery**: Algorithms, C++ warmups, Python logic, and advanced data structures.
2. **Object-Oriented Architecture**: Class hierarchies, inheritance, polymorphism, MRO (Method Resolution Order), and design patterns.
3. **Data & Web Services**: SQLite database design, Streamlit GUI dashboards, and FastAPI/Flask-style REST endpoints.
4. **Agentic AI & Multimodal LLMs**: Building autonomous chatbots, tool-calling agents, Natural-Language-to-SQL database agents, email automation agents, PDF document reasoning, and vision-enabled web camera agents.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your environment:
- **Python**: Version `3.10` or higher
- **C++ Compiler**: `g++` / `clang` / MSVC (for C++ warm-up modules)
- **Git**: For version control

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/Agentic-AI.git
   cd Agentic-AI
   ```

2. **Create and Activate a Virtual Environment**:
   - **On Windows**:
     ```powershell
     python -m venv venv
     .\venv\Scripts\activate
     ```
   - **On macOS/Linux**:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```

3. **Install Core Dependencies**:
   ```bash
   pip install langchain langchain-community openai google-generativeai streamlit opencv-python python-dotenv
   ```

---

### Environment Variables (`.env`)

For Phase 5 (Agentic AI & LLM modules), create a `.env` file in the relevant subfolder (or workspace root) containing your API keys:

```ini
# LLM Provider API Keys
OPENAI_API_KEY=your_openai_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
NVIDIA_API_KEY=your_nvidia_api_key_here
CEREBRAS_API_KEY=your_cerebras_api_key_here

# Email Configuration (for email agent)
SENDER_EMAIL=your_email@example.com
SENDER_PASSWORD=your_app_password_here
```

> ⚠️ **Important**: Ensure `.env` is listed in `.gitignore` so your API keys are never committed to version control.

## 🌟 Featured Agents & Projects

### 🧠 1. NL-to-SQL Database Agent (`20. database agent` / `24. Langchain -DB OPs`)
Translates natural language questions into executable SQL queries, runs them against SQLite databases, and formats the response for end users.

### ✉️ 2. Autonomous Email Agent (`25. building Email Agent` & `send mail`)
Leverages custom tool execution to compose, format, and send emails via SMTP using multi-provider models (OpenAI, Gemini, NVIDIA).

### 📷 3. Vision Web Camera Agent (`26. Web Camera Agent`)
Captures snapshots from a local webcam feed and passes images to multimodal models for real-time visual reasoning and scene description.
