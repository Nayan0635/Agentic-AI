| Command                         | What it does                                        |
| ------------------------------- | --------------------------------------------------- |
| `git status`                    | Shows what changed                                  |
| `git add .`                     | Stages all changes                                  |
| `git commit -m "message"`       | Saves staged changes as a commit                    |
| `git push`                      | Uploads commits to GitHub                           |
| `git pull`                      | Downloads latest changes from GitHub                |
| ------------------------------------------------------------------------------------- |
| `git add filename`              | Stages one file                                     |
| `git clone URL`                 | Downloads a GitHub repository                       |
| `git init`                      | Turns a folder into a Git repository                |
| `git log`                       | Shows commit history                                |
| `git log --oneline`             | Shows compact commit history                        |
| `git diff`                      | Shows unstaged changes                              |
| `git diff --staged`             | Shows staged changes                                |
| `git restore filename`          | Discards unstaged changes to a file                 |
| `git restore --staged filename` | Unstages a file                                     |
| `git rm filename`               | Deletes a file and stages the deletion              |
| `git rm --cached filename`      | Stops tracking a file but keeps it on your computer |
| `git branch`                    | Shows branches                                      |
| `git branch branch-name`        | Creates a branch                                    |
| `git switch branch-name`        | Switches branches                                   |
| `git switch -c branch-name`     | Creates + switches to branch                        |
| `git merge branch-name`         | Merges a branch                                     |
| `git remote -v`                 | Shows connected GitHub repository                   |
| `git ls-files`                  | Shows files currently tracked by Git                |
